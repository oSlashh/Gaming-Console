Image Puzzle Challenge

Ready for the full 10-minute timed session?

This puzzle is a session challenge, not a single-image test. The timer runs for the full game session and does not reset when you choose a new image.

No hints are shown; this is a pure, timed puzzle challenge.

How it works

Start only when ready. The 10-minute countdown starts once the puzzle session begins.

1 Choose or upload an image

Select a beautiful built-in picture or upload your own JPG/PNG/WEBP image to create the board.

2 Solve the shuffled tiles

Use click swap and drag-and-drop to move tiles into the correct position before time runs out.

3 Finish before timeout

You have exactly 10 minutes for the full game session. When the timer reaches 00:00, the full puzzle game resets and you are returned to the menu.
